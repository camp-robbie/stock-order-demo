# 재고 검사 점검

1. docs/requirements.md의 3번·6번 요구사항을 읽는다.
2. 주문 처리 코드와 관련 테스트를 찾아 현재 동작을 확인한다.
3. 재고 = 주문 수량일 때 성공·정확한 차감·주문 내역 1건, 재고 부족 시 409·상태 불변을 확인한다.
4. 요구사항 해석, 근거 파일·메서드, 수정할 파일, 먼저 추가할 테스트, 위험·가정을 보고한다.
5. 파일을 수정하거나 명령을 실행하지 않고 멈춘다.
